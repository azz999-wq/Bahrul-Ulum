# Website Bahrul Ulum Singaparna

Website resmi Pondok Pesantren Bahrul Ulum Singaparna untuk menyajikan informasi pesantren dan mengelola konten publik.

## Fungsi Website

- **Beranda:** profil singkat, program pendidikan, kegiatan, galeri, dan kontak pesantren.
- **PPDB:** informasi penerimaan peserta didik baru.
- **Berita:** daftar berita dan kegiatan pesantren beserta halaman detailnya.
- **Organisasi:** informasi struktur dan pengurus pesantren.
- **Informasi pendukung:** halaman kontak, kebijakan privasi, dan ketentuan layanan.
